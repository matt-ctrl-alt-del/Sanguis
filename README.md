​In Sanguis, you play as a vampire who was awakened deep underground. You make amends with the devil to finally escape in the real world. 
Sanguis is a platformer game. Are you up to the challenge?

Context: I added a lot of new features I have never done before and I am proud of the progress I made while making this game. I plan this to be my first 2-week game, and I have laid the foundation for the project. I have learned a myriad of things such as using particles, pausing the game, a loading screen, a different way for a splash screen, or the buttons in main menu. While bare-bones, I plan to polish this more on the upcoming week and make it juicy because my personal goal of starting this project is learning how to add game juice. This is why I chose to go back to basics and do a platformer instead of my usual maze/top-down game or a mix of two.

To focus on learning new things, I had to sacrifice making art, so some of the art here are not mine or are reused from my past projects. 
Credits: Tilemap Template - https://patrik-arts.itch.io/tileset-templates, Character Sprite - https://nespy.itch.io/hooded-mage-character-assets, Font used - https://www.dafont.com/saltblack-combat.font.

My goal for next week is to make the movement WAAY better, improve the ui by adding a pause/about/options screen, add music/audio design, make an npc for the first time, and overall add game juice.

Controls:
W - Move up
A - Move left
S - Move down
D - Move right
